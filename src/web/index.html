缺失变量

代码引用了这些变量但 .env.example 没有声明 —— 新环境 clone 后启动必炸。需要补声明，envdrift 不会自动写入值。

疑似泄漏

提交到仓库的 env 文件里出现了像真密钥的值。清理后请务必轮换该密钥。

死变量

声明了但代码从未引用。确认无用后可通过清理删除。

动态引用

运行时变量名查找，静态分析无法判定，请人工确认。
